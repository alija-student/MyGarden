# ER Diagram

Current database schema (PostgreSQL), generated by the EF Core migration
`20260929115905_InitialCreate`.

```mermaid
erDiagram
    Gardens ||--o{ PlantPlacements : "contains"
    Plants  ||--o{ PlantPlacements : "is placed as"

    Gardens {
        uuid Id PK
        varchar(200) Name "not null"
        int WidthCm "not null"
        int LengthCm "not null"
        timestamptz CreatedAt "not null"
    }

    Plants {
        uuid Id PK
        varchar(200) CommonName "not null"
        varchar(200) ScientificName "nullable"
        int SpacingCm "not null"
        int MatureHeightCm "not null"
        varchar(20) Sun "FullSun | PartialShade | FullShade"
        varchar(20) Water "Low | Medium | High"
        text Notes "nullable"
    }

    PlantPlacements {
        uuid Id PK
        uuid GardenId FK "indexed"
        uuid PlantId FK "indexed"
        double XCm "from top-left corner"
        double YCm "from top-left corner"
    }
```

## Notes

- **Gardens → PlantPlacements:** deleting a garden deletes its placements (cascade).
- **Plants → PlantPlacements:** also cascade at the moment. Deleting a catalogue plant would
  silently remove it from every garden. Consider `Restrict` once plant management exists.
- Enums (`Sun`, `Water`) are stored as strings, so the database stays readable.
- All sizes and positions are in centimetres; the frontend converts to pixels.
